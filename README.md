# Arrange

Arrange your iPhone and iPad Home Screen from your Mac. Plug in over USB, drag things where you want
them, and apply.

**[Download the Mac app](https://github.com/EchelonOne-io/arrange-releases/releases/latest/download/Arrange.dmg)**

Open the .dmg and drag Arrange to Applications. Rearranging and the sample devices are free; applying a
layout to your own device needs a license key, which you can buy from inside the app.

This repository only hosts the downloads. Every version is listed under
[Releases](https://github.com/EchelonOne-io/arrange-releases/releases).
